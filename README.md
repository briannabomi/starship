# Starship

Starship is the planning repository for the project being built from Bri's WorldCode context.

This repo is meant to be the shared source of truth for future agents and collaborators. Start here before creating strategy, offers, content, product architecture, or implementation plans.

## Repository Map

- `context/source/` contains untouched copies of the original context documents.
- `planning/` contains synthesized planning docs and living project strategy.
- `agent-notes/` contains quick-start orientation for future agents.

## Source Context

- `context/source/Citizen.md` - ICP, pain points, desires, fears, objections, and positioning around "Armored Alex."
- `context/source/WorldCode_Bri.md` - core conviction, world, enemy, citizen/tourist distinction, shared language, and transformation arc.
- `context/source/NorthStar.MD` - brand voice, admired brands, story material, polarizing takes, and legacy orientation.
- `context/source/Offers-Framework.md` - offer-building framework to shape the eventual product or service.

## Working Principle

Starship should preserve the source documents, then build from them in layers. Do not overwrite source context. Add interpretations, decisions, and plans in `planning/` with dates or clear version notes when the project direction changes.
