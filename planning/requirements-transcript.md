## Initial Feature Inventory

### Client Journal And Assignments

- Coach can create journal prompts.
- Prompts can have due dates.
- Clients can write and store journal entries.
- Clients can revisit prior reflections.
- Clients can mark assignments complete.
- Coach receives an alert when a client completes an assignment.

### Fathom Call Recording Intelligence

- System can pull from Fathom recordings or transcript exports.
- System identifies key insights from calls.
- Insights should include internal-world insights.
- Insights should include external-world insights.
- Insights should connect to thought models and Legacy Roadmap updates.
- System extracts action items from recordings.
- Clients receive action items by text message.

### Metrics And Progress Tracking

- System shows where the client is now.
- System shows where the client is going.
- System displays the gaps being closed.
- Metrics should make transformation visible over time.

### Pre-Call Input And Weekly Accountability

- Client can submit questions before calls.
- Client can submit desired area of focus before calls.
- System sends reminders to fill out weekly tracker.
- Weekly tracker supports accountability.

### Legacy Roadmap Workbook

- System can ingest or reference the Legacy Roadmap workbook.
- Current source may be a Google Sheet.
- Future source may be a dedicated app.
- Clients can see their progression through the roadmap.

### Framework And Cosmology Video Library

- System can house recorded videos.
- Videos include frameworks and cosmology teachings.
- Clients can browse a database or library folder.
- Clients can rewatch videos.
- Clients can be pointed to videos by topic.
